# Power BI Portfolio

A collection of Power BI reports (`.pbix`) that I have built, as evidence of my work with Power BI.

**What these reports show**

- Data preparation with Power Query and the M language
- Data modeling: star schema, relationships and date tables
- DAX measures, calculated columns and calculated tables
- Dashboard and report design

**How to open them**

1. Download any `.pbix` file from this repository (open the file, then click **Download raw file**).
2. Open it with [Power BI Desktop](https://www.microsoft.com/power-platform/products/power-bi/desktop) (free).

All data in these files is sample or anonymized data.
